El objetivo de este proyecto es trabajar los conceptos básicos de java. Ciclos, variables, impresión de strings, operaciones aritméticas y principalmente vectores, son los elementos utilizados para crear un modelo de solución a las diferentes instrucciones. Esta actividad me permitió entender la funcionalidad de los vectores, teniendo una lógica era muy similar a python (lenguaje trabajado anteriormente), difiriendo únicamente en la sintaxis y definición de elementos que puede contener el vector. 
El proyecto cumple con cada una de las instrucciones y contempla los escenarios en los que el valor ingresado no cumple con las condiciones, permitiendonos tener control sobre los errores y preservar la ejecucion del programa.
